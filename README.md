# MELRec

Official implementation of **MELRec: Modular End-to-End LLM for Sequential Recommendation**.

This repository is being prepared for the public release of the code and preprocessing scripts accompanying the paper.

## Repository Structure

```text
MELRec/
+-- analysis/       # Analysis and visualization scripts
+-- checkpoints/    # Model checkpoints and experiment outputs
+-- config/         # Dataset, model, and experiment configurations
|   +-- data/
|   +-- exp/
|   `-- model/
+-- data/           # Locally processed datasets (not tracked)
+-- docs/           # Additional documentation
+-- processor/      # Dataset preprocessing utilities
+-- scripts/        # Training and evaluation entry-point scripts
+-- src/            # MELRec source code
`-- tests/          # Tests
```

## Status

The repository structure is currently initialized. Source code, configuration files, and preprocessing scripts will be added before the public release.

## Data and Checkpoints

Datasets and trained checkpoints are not included in this repository. Please obtain the datasets from their original sources and place local copies under `data/`.
